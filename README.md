# Controle Adaptativo de Hiperparâmetros por Lógica Fuzzy em Aprendizado Federado para Sistemas IoT

Implementação do Trabalho de Conclusão de Curso da graduação em Ciência da Computação sobre adaptação de hiperparâmetros em Aprendizado Federado utilizando Lógica Fuzzy.

## Como Executar

O código foi desenvolvido para execução no **Google Colab**.

1. Abra o arquivo `FL_Avg+Fuzzy_DATASET_HAR.ipynb` no Google Colab.
2. Execute as células em ordem, do **ID = 00** ao **ID = 28**, ou clique em **"Executar tudo"**.

## Dataset

O projeto utiliza o dataset **UCI Human Activity Recognition Using Smartphones (UCI-HAR)**, que é baixado e preparado automaticamente durante a execução do notebook.

## Métodos desenvolvidos

- **FedAvg**
- **FedProx**
- **FedAvg + Fuzzy**

## Tecnologias

- Python
- PyTorch
- Scikit-Fuzzy
- Scikit-Learn
- NumPy
- SciPy
- Google Colab
